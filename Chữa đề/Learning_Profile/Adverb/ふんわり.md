Adverb | ふんわり

- **Meaning:** Mềm mại / Mềm xốp / Nhẹ nhàng (Softly / Fluffily).
- **Usage:** Phó từ phỏng thanh/phỏng hình mô tả trạng thái mềm xốp (của chăn, quần áo sau khi giặt mềm, bánh bông lan). Thường đi với `〜する` hoặc `〜させる`.
- **Example:** `洗濯物をふんわりさせるために柔軟剤を入れる。` (Cho nước mềm vải vào để làm quần áo mềm xốp).
- **Trigger:** **ふんわり** + と / させる / する.
- **Contrast:** `ごわごわ` (Thô ráp / Cứng đơ).
- **One-line Summary:** Phó từ trạng thái mô tả sự mềm mại, bông xốp dề chịu.
