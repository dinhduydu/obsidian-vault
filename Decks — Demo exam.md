# Demo exam

This note is an exam deck: it carries the `#decks/exams` tag, so every heading with a task list underneath becomes a multiple-choice question — check the correct answers with `[x]`. Click the deck row (or use the deck's menu) and press Start exam to try it.

Below are all question forms in order: single answer, multiple answers (graded all-or-nothing), true or false, a typed short answer, table rows and cloze blanks. Open this file in source mode to see how each is written — a `%%comment%%` under a question becomes an explanation shown in the results review.

The exam setup dialog lets you pick the number of questions, a time limit, the pass score and more. Reviews and exams track results separately, so you can use both over the same cards.
