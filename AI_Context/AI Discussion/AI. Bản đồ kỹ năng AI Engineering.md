Bản đồ kỹ năng AI Engineering: Using Coding Agents thể hiện cấu trúc phân nhánh các nhóm kỹ năng cần thiết trong kỹ thuật AI, tập trung chi tiết vào nhánh "Using coding agents" (Sử dụng các agent hỗ trợ lập trình).

Cấu trúc tổng quan (Cấp 1 & Cấp 2)

Chủ đề chính là AI Engineering, chia thành 4 trụ cột kỹ năng chính:

* Building and deploying AI applications: Xây dựng và triển khai các ứng dụng AI.

* Software engineering fundamentals: Nền tảng kỹ thuật phần mềm.

* Using coding agents: Sử dụng agent hỗ trợ lập trình (nhánh trung tâm được mở rộng).

* Shaping the build: Định hình quy trình phát triển/xây dựng sản phẩm.

Chi tiết nhánh "Using coding agents" (Cấp 3)

Nhánh này được làm nổi bật (viền tím) và phát triển thành 5 kỹ năng thành phần chính:

* Coding agent foundations: Nền tảng về agent lập trình (hiểu nguyên lý hoạt động, cách vận hành cơ bản của agent).

* Customizing the agent and its environment: Tùy chỉnh agent và môi trường làm việc (cấu hình agent, tích hợp công cụ, thiết lập môi trường phát triển phù hợp).

* Reviewing the work: Kiểm thử và đánh giá kết quả (kiểm tra mã nguồn do agent tạo ra, đảm bảo tính chính xác và chất lượng).

* Enabling agent autonomy: Tối ưu hóa tính tự chủ của agent (cho phép agent tự xử lý công việc phức tạp, tự sửa lỗi hoặc đưa ra quyết định độc lập hơn).

* Directing the workflow: Điều phối quy trình làm việc (lập kế hoạch, giao tác vụ, kiểm soát hướng đi của agent trong toàn bộ dự án
